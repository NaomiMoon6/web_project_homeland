# Projeto 5 — De Pátria para Pátria

Projeto desenvolvido durante o Sprint 5 do curso de Desenvolvimento Web da TripleTen.

O objetivo foi criar uma página responsiva apresentando as cidades natais de funcionários da TripleTen, seguindo o layout disponibilizado no Figma.

## Tecnologias utilizadas

* HTML5
* CSS3
* Flexbox
* Media Queries
* BEM
* Git e GitHub

## Responsividade

O projeto foi desenvolvido para diferentes tamanhos de tela:

* 320px — mobile
* 768px — tablet
* 1280px — desktop

Também foram realizados testes em resoluções intermediárias para garantir uma boa adaptação do layout.
