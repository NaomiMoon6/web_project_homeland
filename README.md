## 📌 Sobre o Projeto

O **De Pátria para Pátria** é uma página web institucional e responsiva desenvolvida para apresentar as cidades natais dos funcionários da TripleTen, utilizando como base o layout disponibilizado via Figma.

Desenvolvido durante o Sprint 5 do bootcamp de Desenvolvimento Web da TripleTen, o projeto teve como foco garantir uma experiência de navegação fluida em múltiplos dispositivos, aplicando técnicas avançadas de responsividade e a metodologia BEM para a estruturação do código CSS.

---

## 🎯 Objetivos de Aprendizado

* Criar layouts totalmente **responsivos e adaptáveis** a diferentes tamanhos de tela.
* Aplicar **Media Queries** para refatorar o design conforme a resolução do dispositivo.
* Implementar a metodologia **BEM (Block Element Modifier)** para organizar, nomear e reutilizar classes CSS.
* Aperfeiçoar o fluxo de trabalho com **Git e GitHub** para versionamento de código e publicação.

---

## 🛠️ Tecnologias e Conceitos Utilizados

* **HTML5**:
* Estruturação semântica da página para garantir acessibilidade e boas práticas de SEO.
* Inserção de conteúdo multimídia, textos e elementos interativos.


* **CSS3**:
* **Flexbox**: Distribuição dinâmica e alinhamento dos componentes na tela.
* **Media Queries**: Definição de pontos de quebra (*breakpoints*) estratégicos para suporte a diferentes dispositivos.
* **Metodologia BEM**: Organização do código CSS de forma modular, sustentável e escalável.


* **Git & GitHub**:
* Versionamento de código, controle de histórico e hospedagem do projeto.



---

## 📱 Responsividade e Breakpoints

O layout foi planejado e adaptado para entregar uma interface consistente em diversos tamanhos de tela:

* **Mobile**: 320px
* **Tablet**: 768px
* **Desktop**: 1280px

> *Também foram realizados testes e ajustes em resoluções intermediárias para assegurar uma transição suave entre os breakpoints.*
